Lab 03
Linear systems: Gaussian elimination and Gauss-Seidel

Gaussian elimination reduces the matrix to triangular form before back substitution. Gauss-Seidel updates each unknown using the newest available values.

Each Q file is a separate program. Open Q1.cpp, Q2.cpp, or Q3.cpp and follow main() from top to bottom.
Compile one file at a time: g++ -std=c++17 Q1.cpp -o Q1
