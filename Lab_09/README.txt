Lab 09
Numerical integration: Trapezoidal, Simpson and Romberg

The trapezoidal rule uses linear segments. Simpson rules use quadratic/cubic panels. Romberg improves trapezoidal estimates by extrapolation.

Each Q file is a separate program. Open Q1.cpp, Q2.cpp, or Q3.cpp and follow main() from top to bottom.
Compile one file at a time: g++ -std=c++17 Q1.cpp -o Q1
