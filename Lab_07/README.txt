Interpolation: Newton divided differences

The divided-difference table supplies the Newton polynomial coefficients. Evaluate it using a nested product to avoid repeatedly expanding the polynomial.

Each Q file is a separate program. Open Q1.cpp, Q2.cpp, or Q3.cpp and follow main() from top to bottom.
Compile one file at a time: g++ -std=c++17 Q1.cpp -o Q1
