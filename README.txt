NUMERICAL METHODS LABS - READABLE C++ SOLUTIONS
================================================

Each available lab sheet has its own folder. Each question is a separate, standalone C++17 program.

HOW TO COMPILE (one question at a time)
  g++ -std=c++17 Q1.cpp -o Q1
  ./Q1

Use Q2.cpp or Q3.cpp for the other questions. The programs use descriptive spacing, indentation,
comments, and ordinary step-by-step control flow to make them easier to study.

AVAILABLE SOURCE SHEETS
  Lab 1, 2, 3, 4, 6, 7, 8, 9, 10, and 12.

IMPORTANT SOURCE NOTE
The PDF uploaded with a filename containing "Sheet-11" is headed LAB SHEET-12 inside the document.
It is therefore placed in Lab_12. No Lab Sheet 5 was supplied. No Lab_11 solution has been invented.

EXAM PREPARATION TIP
For each program, learn (1) the formula, (2) what each loop updates, (3) the stopping condition,
and (4) what the printed result means. Compile and run each question yourself at least once.
