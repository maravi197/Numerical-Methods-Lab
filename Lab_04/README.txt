Lab 04
Iterative linear solvers: Jacobi, Gauss-Seidel and SOR

Jacobi uses only the previous iteration. Gauss-Seidel uses newly computed values immediately. SOR adds a relaxation factor omega.

Each Q file is a separate program. Open Q1.cpp, Q2.cpp, or Q3.cpp and follow main() from top to bottom.
Compile one file at a time: g++ -std=c++17 Q1.cpp -o Q1
