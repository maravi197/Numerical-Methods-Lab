Lab 12 - ODE Solvers and Boundary-Value Problems

This lab focuses on solving ordinary differential equations using numerical methods.

- Q1: Compare RK4 and Modified Euler methods.
- Q2: Use RK4 for initial values and Adams-Bashforth-Moulton for later steps.
- Q3: Solve a boundary-value problem using a finite-difference method.

Each question is written as a separate C++ program.
Open Q1.cpp, Q2.cpp, or Q3.cpp and read it from main() downward.

Compile each file separately, for example:
  g++ -std=c++17 Q1.cpp -o Q1
  g++ -std=c++17 Q2.cpp -o Q2
  g++ -std=c++17 Q3.cpp -o Q3
