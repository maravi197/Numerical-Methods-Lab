Root finding: Newton and fixed-point methods

Newton updates x using f(x)/f'(x). The system version solves the Jacobian correction equations. Fixed-point iteration repeatedly evaluates phi(x); Aitken accelerates the sequence.

Each Q file is a separate program. Open Q1.cpp, Q2.cpp, or Q3.cpp and follow main() from top to bottom.
Compile one file at a time: g++ -std=c++17 Q1.cpp -o Q1
