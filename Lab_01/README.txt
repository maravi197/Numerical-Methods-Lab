Lab 01
Root finding: Bisection and Regula Falsi

Both methods keep a bracket [a,b] where the function changes sign. Bisection halves the interval; Regula Falsi uses a straight-line estimate.

Each Q file is a separate program. Open Q1.cpp, Q2.cpp, or Q3.cpp and follow main() from top to bottom.
Compile one file at a time: g++ -std=c++17 Q1.cpp -o Q1
